The authorized local repair is deliberately limited to these evidenced clauses:

- LOG and POWER coerce an explicit Missing slot as numeric zero. They broadcast
  both arguments across the union of array dimensions with singleton expansion.
  Padding supplies NA at its own argument position, followed by left-to-right
  scalar coercion. Earlier coercion errors therefore survive later padding.
- LOG applies the same scalar numeric coercion to array and reference elements.
  Its omitted base remains distinct from an explicit Missing base. A subsequent
  paired packet supplies 585 identical inputs to omitted LOG, explicit base ten,
  and LOG10. Every omitted result agrees with LOG10; 319 differ from explicit ten.
  The omitted branch therefore selects the existing dedicated LOG10 kernel.
  The four original one-ULP failures remain retained in the failed baseline.
- MEDIAN ignores Empty and includes explicit Missing as zero, before its existing
  direct/range aggregate numeric policy. The shared aggregate helper is unchanged.
- FISHER has no repair justified by this packet and remains unchanged.

A new narrow `elementary_prepared` helper initially serves LOG and POWER. The
subsequent MROUND owner reuses its ordered pair operation after a separate
function-local kind mapping; MROUND does not inherit LOG/POWER Missing or logical
policy. This reuse makes no change to the helper or generic adapters.
The generic unary/binary numeric adapters and aggregate coercion policies remain
unchanged. POWER's generated by-index arm currently bypasses `eval_power_surface`,
so its generator and generated arm must select that function-specific surface.
OP_POWER retains its existing operator route. Numeric Q dispatch still calls the
unchanged POWER kernel. Both ordinary value dispatch and the index route must be
exercised to prevent a surface-only repair that production callers never use.
