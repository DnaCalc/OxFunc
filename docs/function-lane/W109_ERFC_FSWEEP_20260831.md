## Why this sweep, not more NSWC PQR last-bit cubes

The 26-bit NSWC/Cody store cubes are exhausted. The leftover is F, scored
against `F_or = Q / excel_exp(-RN53(RN64(z·z)))`. Mid NSWC residual is a
last-bit comb (75% ≤1 ULP), not a 7-ULP family wall.

New readings from `residual-nswc-mid.tsv` (7741 mid rows):

1. The single 7-ULP row is `z = 1.1842387490730035`, the known G-F3
   direct-ERFC vs implied-NORMSDIST conflict. Direct bits already win in
   the merge; the miss is still a real ERFC.PRECISE residual, but it is
   not a band-wide ceiling.
2. Residual sign flips with the published NSWC cut: below 2, NSWC runs
   high; above ~2.5, NSWC runs low. That is a branch-fingerprint, so
   internal PQR / AA-BB / CC-DD cuts and t-association are live discrete
   trees (not coefficient last-bit).
3. ULP≥4 rows cluster in `z ∈ [0.77, 1.06]` (plus a few AA-BB points).
   A named-site x87 store diagnosis on that cluster is cheaper than
   another 26-bit cube.
