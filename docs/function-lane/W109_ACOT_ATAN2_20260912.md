# ACOT = ATAN2(x, 1) (2026-09-12)

Live Excel 16.0 build 20326 / CV2, Range.Value2 inject.

`ACOT(x)=ATAN2(x,1)` 28/28 including subnormal `x`, `±1e-200`, `±1e200`,
and `1e300`. `PI()/2-ATAN(x)` is 7/10 (x=2 is 1 ULP; x=4 is 5 ULP).
`ATAN(1/x)` matches only the positive half (5/10).

Production uses C `atan2(1, x)` rather than `atan2_kernel`: that kernel's
`|y/x|`-overflow `#NUM!` guard would reject subnormal `x` even though
Excel `ATAN2(x,1)` and `ACOT(x)` both publish π/2 there.
