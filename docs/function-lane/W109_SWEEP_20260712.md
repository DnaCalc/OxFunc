Excel's FORECAST is NOT the LINEST pipeline. Identified kernel
(65/65 bit-exact over discovery + adversarial: 1e12 common offsets, n=2,
near-constant x, constant y, n=12 irregular, subnormal magnitudes):

    mx = (Σx)/n ; my = (Σy)/n           forward sums, plain double
    num = Σ (x-mx)(y-my) ; den = Σ (x-mx)²   one fused loop
    b = num/den ; a = my - b·mx ; result = a + b·x   (intercept form)

kernel with pinned witnesses; full lib suite green (1497).
